# CraftCycle System

## Project Overview

CraftCycle is a comprehensive system built to facilitate the recycling and upcycling of materials. It connects people looking to dispose of scrap materials with those who can craft or upcycle them into new products. The system boasts features such as a marketplace, a DIY hub, community forums, a scanner, challenges, and a specialized coin-based reward system.

## Project Structure

The project is divided into three main components:

1. **[craftcycle_frontend](./craftcycle_frontend/README.md)**  
   The user interface of the application, built with HTML, CSS, and JS. It includes numerous pages such as the marketplace, DIY hub, community, challenges, and scanner.

2. **[craftcycle_backend](./craftcycle_backend/README.md)**  
   The server-side component built in Python (likely using a micro-framework like Flask or FastAPI based on the routing structure). It handles APIs for authentication, products, scanning, marketplace, and administration.

3. **[craftcycle_database](./craftcycle_database/README.md)**  
   The database layer for storing structured data like users, scrap materials, products, scan histories, and coin transactions.
